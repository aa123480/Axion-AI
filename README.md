# AI-Powered Gaming Coach & Stats Platform

Axion AI is a full-stack web app that will help gamers in improving their skills and find information by providing them AI-based coaching services, match analysis, and statistics. Axion AI is built on FastAPI and modern web technologies, that provides real gameplay daat to give feedback for players of all skill levels.
